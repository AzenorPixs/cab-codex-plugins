# Conception

La liste monitorScripts contient permission-policy, dépendance transitive de son client. Une table destination→source remplace la vérification source seule. Pour chaque import relatif statique ./ ou ../, résoudre depuis l’artefact source et depuis sa destination ; l’artefact déclaré à la destination attendue doit provenir du fichier source attendu. Ainsi un module seulement présent dans un autre groupe ne satisfait pas l’import. Aucun fichier préexistant non déclaré ne peut masquer un paquet incomplet.

La validation reste avant tout arrêt, avec la même erreur update-package-import-missing. L’import ESM du client installé est exercé pour le layout géré. Les contrôles ask et le mode de récupération MCP restent identiques à29/28. Le repli29 étant terminal, la nouvelle installation peut avoir son reçu distinct sans effacer ni reclasser l’ancien.
