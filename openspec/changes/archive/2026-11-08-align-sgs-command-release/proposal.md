# Aligner les commandes sur la distribution CAB

## Why

La commande SGS annonce une version antérieure aux commandes CAB et CABU. CABU exige pourtant un jeu de versions identiques avant publication des commandes.

## What Changes

Aligner le frontmatter de SGS sur la version distribuée et vérifier automatiquement les versions des quatre commandes CAB, CABU, SGS et CCAB. Ne modifier ni le comportement SGS ni les RUN.
