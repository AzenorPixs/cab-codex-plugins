# Faire converger les connexions MCP

## Why
Un agent peut garder un ancien moteur ou plusieurs relais après une mise à jour.

## What Changes
Surveiller version et nombre de liaisons. Garder les canaux indépendants dont les deux extrémités sont prouvées. Demander des reprises bornées tant que la convergence manque. Notifier le début du défaut et le retour vérifié.
