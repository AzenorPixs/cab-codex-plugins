# Conception

Le champ ouvrant montre les choix actifs et permet d’ajouter ou retirer chaque fournisseur par un bouton sélectionnable. Une sélection vide affiche Tous les fournisseurs. Le serveur considère les tableaux vides déjà stockés comme des sélections sans filtre, en plus de la valeur nulle historique. Il conserve l’écriture canonique nulle pour les nouvelles sélections vides. Le schéma PostgreSQL reste compatible avec les versions précédentes.
