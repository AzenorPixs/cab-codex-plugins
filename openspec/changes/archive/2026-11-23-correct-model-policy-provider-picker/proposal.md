# Corriger le sélecteur de fournisseurs des politiques

## Why

Les fournisseurs doivent être sélectionnés dans un champ dédié et l’absence de sélection doit inclure le catalogue de tous les fournisseurs.

## What Changes

- Placer le champ Fournisseurs sous le bloc Modèles à inclure, dans un bloc distinct.
- Remplacer les cases par une liste ouvrante à choix multiples.
- Traiter les sélections vides comme le mode Tous.
