# Conception

Reconnaître seulement `search(<objet de données littérales>); return <chaîne JSON littérale>;`. Le parseur statique ne reçoit aucun évaluateur JavaScript. La liste toolCalls doit contenir exactement search, terminé, avec les mêmes arguments ; troncature ou appel supplémentaire refuse la projection. La partie devient uniquement cab_codemode_discovery avec empreinte native. Son texte n'est jamais interprété comme un état, une décision ou une preuve métier.

Les chemins MCP exécutables, permissions, fins et once restent inchangés. Les autres programmes restent bloquants. La candidate et ses historiques ne changent pas ; après CABU, le rejet est scellé sous l'accord humain déjà acquis, puis un prévol neuf est exigé.

Ce complément corrige une forme du raccord observée pendant l'exécution du périmètre autonome SCM Code Mode validé le 29 octobre 2026 ; il ne rouvre pas l'archive 2.1.8 et ne crée aucune fonctionnalité Pixs. Un incrément correctif commun évite de remplacer les artefacts publiés de même version.
