# Conception — code non attribué

La résolution 3840 × 2160 reste la référence visuelle. Les règles adaptatives s’appliquent aux largeurs contraintes, sans changer les données ni les opérations métier.

Les tableaux de sessions et d’archives conservent leur structure HTML et leurs en-têtes ; chaque cellule reçoit un libellé utilisé par la présentation empilée. Les chemins et fenêtres peuvent se replier sans déborder. Sur téléphone, l’en-tête ne réduit pas durablement la zone visible ; les informations longues des agents peuvent revenir à la ligne.

La construction et les contrôles ciblés utilisent les outils déclarés dans `DEVOPS.md`. Les vérifications de rendu portent sur les formats effectivement disponibles sur l’hôte ; leurs limites sont conservées dans les preuves.
