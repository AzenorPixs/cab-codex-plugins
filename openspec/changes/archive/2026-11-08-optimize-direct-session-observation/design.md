# Conception

SGS expose une lecture locale limitée aux identités et bornes des liaisons directes du projet. Elle ne parcourt pas les événements de télémétrie. Le moniteur utilise cette lecture pour ses RUN ; la vue Stats conserve le calcul SGS complet. L'indisponibilité de la source reste signalée et ne masque pas les RUN pilotés. Les contrôles de socket, propriétaire et projet restent applicables.
