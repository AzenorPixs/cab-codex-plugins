# Conserver les preuves de requalification du partage MCP

## Why

L’index libéré du RUN d’étude conserve le snapshot d’origine. Le dossier de qualification a depuis évolué dans le dépôt.

## What Changes

Préparer l’archive du change requalifié dans un index indépendant, en conservant le snapshot et les reçus de l’étude. Cette opération documentaire ne déclenche aucune livraison.
