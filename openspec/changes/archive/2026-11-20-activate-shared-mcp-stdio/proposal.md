# Appliquer la limite d’une liaison MCP par agent

## Why

Plusieurs relais Codex Desktop authentifiés utilisent encore des versions distinctes de CAB. Le partage de l’app-server permet à plusieurs sessions natives d’utiliser une liaison unique.

## What Changes

Activer le partage pour les clients Codex qui le proposent, préserver les rattachements natifs par appel et surveiller strictement le nombre et la version des liaisons de tous les agents. Réutiliser la reprise native et, pour un bureau compatible observé, la reprise contrôlée de CABU.
