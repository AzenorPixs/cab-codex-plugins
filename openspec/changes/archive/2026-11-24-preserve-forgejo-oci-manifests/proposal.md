## Why

La publication réelle de PFD 1.0.2 sur Forgejo confirme les tags mais la rétention échoue sur les lignes de paquet représentant les manifestes enfants d’un index OCI.

## What Changes

- Séparer les entrées de manifeste indexées par empreinte des tags soumis à la rétention.
- Réconcilier, sur preuve, le reçu hérité d’une publication exclusivement Docker Forgejo arrêtée sur cet inventaire.
