# Ajouter les métadonnées de base de données et de spécifications

## Why

Les projets doivent pouvoir déclarer leur base et ses composants de données
ainsi que l’outil qui porte leurs spécifications.

## What Changes

- Ajouter PROJECT_DB et PROJECT_SPECIFICATIONS à la rangée qui suit les
  langages et les frameworks, avec une aide dédiée.
- Projeter les valeurs dans PostgreSQL et les diffuser via Electric.
- Afficher les technologies déclarées dans le bloc Configuration.
