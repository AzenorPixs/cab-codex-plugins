# Conception

Les douze onglets reprennent le cumul déjà calculé par étape. Le même encadré contient une grille de durées et, à droite, le groupe des tokens. Sur largeur réduite, la grille se replie en une colonne et les tokens suivent la ligne Attente. Les rôles visibles en session pilotée sont identifiés.

Informations et la ligne de cumul dans Résumé exploitent la synthèse persistée du RUN. Son champ de tokens agrège les lignes déjà rattachées aux itérations du RUN. La projection existante calcule et diffuse les valeurs par Electric. Si aucun compteur n’est observable, l’interface affiche un tiret. La mise en œuvre ne requiert aucune migration de schéma.
