# Présentation commune de la zone Projets

Sur l'accueil sans projet sélectionné, réutiliser les classes project-tabs et
project-home-link avec le même SVG que la navigation d'un projet. Conserver les
messages d'information et le titre Projet introuvable pour un identifiant erroné.

Dans ProjectSidebar, remplacer le texte du h2 par un Link vers /projects.
Conserver le bouton d'ajout et les liens de projets. Ce composant commun couvre
l'accueil, les projets et leurs sous-pages, les RUN et la création.

Vérifier le build et Chromium sur l'hôte, reporter les deux composants dans le
projet puis indexer et libérer par CAB, sans livraison ni modification de version.
