# Fabrique des artefacts du projet

## Why

Les paquets Debian et images Docker déjà construits doivent être consultables depuis le projet. Les opérateurs ont besoin d’un contrôle de construction manuel pour chacun de ces formats.

## What Changes

Ajouter la page Fabrique, l’inventaire PostgreSQL des derniers artefacts et deux constructeurs locaux CAB compatibles avec les recettes Debian et Docker utilisées par DIU.
