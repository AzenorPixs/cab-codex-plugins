# Supprimer les pages Archives dédiées

Code de lot non attribué.

## Pourquoi

Les pages Archives dédiées doublonnent les onglets Archivées des pages Sessions.

## Périmètre

- Retirer les routes Web dédiées et leurs entrées de navigation.
- Afficher les sessions archivées dans les onglets Archivées existants, au niveau global et par projet.
- Ramener le développeur depuis le détail d’un RUN remplacé à l’onglet Archivées de son projet.
- Conserver le service d’archivage, ses données, ses autorisations et la pagination. Aucune migration.
