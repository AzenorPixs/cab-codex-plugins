# Confier l’admission des fichiers à l’autorité du RUN

Code de lot non attribué.

Le propriétaire d’un RUN direct dispose déjà du mandat pour les fichiers cadrés.
L’obligation de passer par un administrateur pour inclure un fichier préexistant
bloque la livraison TED 0.7.29 sans arbitrage supplémentaire à effectuer.

Les deux commandes d’admission existantes reconnaissent le propriétaire en
direct et l’orchestrateur désigné en piloté. L’ancienne voie administrative
reste compatible en direct. Les réservations temporaires, les empreintes
et la vérification de l’index continuent de coordonner les sessions.
