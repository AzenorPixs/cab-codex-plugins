## ADDED Requirements

### Requirement: Distribution du catalogue de cycle 1.5.0
Le plugin MUST distribuer le catalogue partagé avec contexte de job et moniteur. Le protocole et le skill MUST documenter les déclarations explicites, retours et états non applicables. Toutes les briques MUST conserver la version 1.5.0 ; cette livraison MUST NOT modifier les services ou profils actifs.

#### Scenario: Jeu source complet
- **WHEN** la préparation source est qualifiée
- **THEN** le catalogue importé, les références distribuées et les tests sont présents sans incrément de version
