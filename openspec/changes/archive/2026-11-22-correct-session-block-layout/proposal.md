# Corriger la présentation du bloc Session

## Pourquoi
Le titre hérite du style du bandeau de l’application et les onglets apparaissent sous lui. Les preuves et les actions demandent une ouverture manuelle.

## Changements
- Rattacher les onglets au bloc au-dessus de son titre commun, avec le style forge.
- Alléger Informations et rendre visibles les preuves et les tâches.
- Séparer le résumé du cycle des détails d’étape, accessibles directement et sans accordéon.

## Impact
Interface Web du RUN et spécification publication-cycle. Aucun changement de données.
