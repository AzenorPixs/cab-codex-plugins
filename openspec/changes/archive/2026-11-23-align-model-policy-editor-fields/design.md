# Conception

Le pied du tableau partagé regroupe Dernier et la recherche dans l’ordre d’utilisation demandé. Pour une politique, les actions d’édition et de suppression suivent ce groupe. Le filtrage et la navigation réutilisent les contrôles existants. L’Overview emploie une grille pour associer chaque libellé de Triage à son sélecteur. Aucune migration n’est nécessaire.
