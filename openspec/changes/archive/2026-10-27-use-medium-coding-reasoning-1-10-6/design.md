# Conception

Le contrôleur utilise la variante `medium` comme unique niveau automatique.
Une valeur `reasoning` explicitement transmise par le prompt reste prioritaire
et exacte. Les capacités proviennent toujours de l'observation OpenCode ; le
prévol natif, sa corrélation et la conservation du choix restent obligatoires.

Le changement est une préparation de sources. Il ne modifie aucune
configuration ou brique active. La base de version distribuée devient 1.10.6.
Les références qui décrivent une qualification ou une version antérieure
restent historiques ; 1.10.5 est conservée parmi les versions chargées
compatibles lorsque le profil de maintenance l'exige.
