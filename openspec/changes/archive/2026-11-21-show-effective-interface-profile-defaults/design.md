# Conception

Le catalogue fournit les références lues dans les règles responsives
existantes. Ces références servent uniquement au formulaire. Un réglage
enregistré conserve sa priorité. En l’absence de réglage propre au profil,
une valeur fixe est affichée ou le champ indique Automatique quand le
navigateur calcule la valeur. Les réglages qui couvrent plusieurs variantes
désignent le composant de référence quand nécessaire.

Les réglages de Général et de Résolutions conservent les références en
pourcentage déjà appliquées. Aucun changement de CSS, de données ou de
facteur d’échelle ne résulte de l’affichage des références.
