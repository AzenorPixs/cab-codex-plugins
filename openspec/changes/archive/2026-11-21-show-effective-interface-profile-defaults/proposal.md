# Afficher les valeurs de référence propres à chaque résolution

## Why

Les sous-onglets utilisaient la même valeur nominale, même lorsque le CSS
appliquait déjà une autre valeur à la résolution sélectionnée.

## What Changes

Afficher les références réelles des profils et indiquer les dimensions
calculées automatiquement. Garder la 4K comme référence et conserver le
rendu et les personnalisations existants.
