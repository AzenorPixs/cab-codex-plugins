# Rendre à l’administrateur Web la main sur Git

Les réservations des sessions de codage coordonnent les agents. Elles ne
doivent pas refuser une indexation ou un commit explicitement demandé par
l’administrateur dans le Web.

Le contrôle d’identité, la sérialisation des opérations Git, le périmètre
confirmé de l’indexation et les reçus des sessions restent applicables.
